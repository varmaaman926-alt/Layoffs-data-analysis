# World Layoffs Data Analysis

End-to-end analysis of global company layoffs using **SQL, Excel and Power BI**.

## Project Overview
This project cleans a raw layoffs dataset in MySQL, analyses it with pivot tables in Excel, and presents the insights in interactive dashboards in Excel and Power BI.

## Tools Used
- **MySQL Workbench:** data cleaning
- **Excel:** pivot tables, charts, slicers, dashboard
- **Power BI:** interactive dashboard

## Process
1. **Data cleaning (SQL):** removed duplicates, standardised text fields, handled NULL and blank values, and dropped unusable rows.
2. **Analysis (Excel):** built pivot tables and charts by industry, country and year, with slicers for filtering.
3. **Dashboards:** Excel and Power BI dashboards with a Total Laid Off KPI and filters.

## Key Insights
- [Industry with the most layoffs]
- [Country with the most layoffs]
- [Year or period with the highest layoffs]
